# What I already know about Java

> Java is an interpreted language that runs virtually everywhere on top of the Java Virtual Machine
> It is compiled by the Java Compiler to bytecode and then executed by JVM Just In Time compiler on
> the fly.

It is a language suited for large-scale projects, backend web application architectures that are highly
secure and robust.In addition to the JVM other components like Java FX are all encompassed into the 
Java Development Kit that is distributed as OpenJDK which us developers install and use for developing
Java applications.
