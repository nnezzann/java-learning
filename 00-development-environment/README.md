# Java Development Environment

## What I already know

> Java is an interpreted language that runs virtually everywhere on top of the Java Virtual Machine
> It is compiled by the Java Compiler to bytecode and then executed by JVM Just In Time compiler on
> the fly.

It is a language suited for large-scale projects, backend web application architectures that are highly
secure and robust.In addition to the JVM other components like Java FX are all encompassed into the 
Java Development Kit that is distributed as OpenJDK which us developers install and use for developing
Java applications.

## Components of the JDK

JDK or the Java Development Kit contains the following components :

**Java Virtual Machine** : This in essence is used for executing bytecode. It's roles are :
    
    - Loading classes
    - Verifying bytecode
    - Garbage Collection
    - Memory management
    - Executing bytecode
    - Providing the runtime environment for Java applications
    - JIT compilation

This was originally coming with the JRE along runtime libraries but now OpenJDK comes with tools required
to develop and run java applications.
